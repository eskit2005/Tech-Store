🎮 Tech-Store — Physical Games Store Web Application

A full-stack web application for managing and selling physical video games, built with Spring Boot (backend) and React (frontend).
The system provides RESTful APIs, database migrations, and API documentation, following clean architecture and industry best practices.

📌 Project Overview

Tech-Store is a modern web application designed for a physical video game store.
It allows management of games, categories, customers, and orders while providing a clean API that can be consumed by any frontend client.

Key Goals

Clean backend architecture using Spring Boot

Reliable database versioning with Flyway

RESTful API design

Secure and scalable structure

Developer-friendly documentation using Swagger

Modern frontend using React
